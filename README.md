# ¿Dónde está más barato? (versión PC)

Comparador de precios de productos básicos entre Palí, Walmart, Mega Super, Más x Menos y Auto Mercado en Costa Rica.

## Publicar con GitHub Pages
1. Creá un repositorio llamado `mas-barato-pc` y subí todo el contenido de esta carpeta.
2. En el repo: **Settings → Pages → Deploy from a branch → main / (root)**.
3. Abrí `https://TU-USUARIO.github.io/mas-barato-pc/`.
4. En `index.html` reemplazá `TU-USUARIO` por tu usuario de GitHub (aparece en 2 líneas, para la vista previa al compartir el link).

## Archivos
- `index.html`: la app
- `logo.png`, `favicon.ico`, `favicon.svg`, `icons/`: logo e íconos
- `og-image.png`: imagen de vista previa al compartir
- `manifest.webmanifest` y `sw.js`: permiten instalarla como app y usarla sin conexión
